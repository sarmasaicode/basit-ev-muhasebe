# Basit Ev Muhasebe v3.0.0

- Orhan Gazi uygulamasının güncel menüleri, sayfaları, ayarları ve işlevleri logosuz/genel kullanıma yönelik V2'ye aktarıldı.
- Yönetici hesabından en fazla 5 ek kullanıcı oluşturma; kullanıcı başına görüntüleme, kayıt ekleme, düzeltme ve silme izinleri.
- Bağışçı düzeltme/silme işlemleri ile bağlı gelir kaydının güncellenmesi.
- Kişilerim kayıtlarını düzenleme ve arşivleme.
- Sabit bağışçı tablosundaki ay başlıklarını ödeme hücreleriyle hizalama.
- İlk çalıştırmada temiz bir `veriler/` klasörü oluşturulur; Windows ve Linux taşınabilir ZIP'leri.

Bu, tamamlanmış özellikleri içeren son sürümdür. Önceki beta indirmeleri yayından kaldırılmıştır.
